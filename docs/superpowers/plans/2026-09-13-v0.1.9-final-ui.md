# ResourcePortal v0.1.9 Final Web UI Implementation Plan

## Goal
Implement the final ResourcePortal Web Console defined by the current Penpot design while preserving the v0.1.8 backend/API contracts as the source of truth for data, permissions, runtime and mutations.

## Implementation sequence
1. Extend the manual router to preserve deep tenant/platform subpaths and add route helpers for application, App Group, deployment and resource detail views.
2. Replace the legacy dark shell with the Penpot light shell, responsive navigation, topbar, search/help/notification controls and proper ResourcePortal branding.
3. Introduce a small reusable UI system (icons, buttons, cards, tabs, badges, tables, forms, dialogs, loading/empty/error states) using Tailwind CSS 4 utilities and token variables.
4. Implement Tenant Overview and Applications as curated product pages backed by existing APIs.
5. Implement Create App Group and the routed App Group workspace: Overview, Apps, Config, Networking, Deployments, Activity and Settings.
6. Implement Application detail, the five-step creation wizard, routed edit/config/networking/advanced flows, confirmation states and real attachment/config mutation orchestration with cleanup on failed creation.
7. Implement productized tenant resource pages for volumes, registries, domains, billing/quota, people/access, credentials, operations and audit, using existing endpoints and domain-specific labels/actions instead of raw JSON CRUD.
8. Implement the final platform-administration surfaces and auth/tenant-selection experience while keeping ZITADEL delegation.
9. Add/refresh tests for router, shell, dashboards, App Groups, applications, wizard, forms, destructive actions, permissions and UI states. Run web tests/lint/build and full repository tests/lint/build.
10. Export representative Penpot boards and compare layout/spacing/typography before release.
11. Rebase/merge current main as needed, review diff/secrets/debug code, commit and push branch, open PR, wait for green CI, merge, tag/release v0.1.9 using repository workflow.
12. Patch ResourcePortal Wiki Implementation Stages and affected Web Console/Application documentation with verified AS-IS v0.1.9 information, including PR/commit/tag and test/CI evidence.

## Design source
Penpot page `ResourcePortal — Visual Guidelines`, including Dashboard, Applications, App Group workspace, Application wizard/edit/config/networking screens, tenant resource screens, Platform Admin, Login/SSO and tenant selection.

## Verification gates
No release tag until all requested local test/lint/build commands pass and CI is green. No Wiki COMPLETE/AS-IS statements for behavior that was not verified.
